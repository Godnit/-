# مفتاح Keyboard 1.0

كيبورد أندرويد عربي/إنجليزي خفيف ومخصص، مبني Native Java بدون مكتبات خارجية وقت التشغيل.

## الميزات
- العربية والإنجليزية والرموز والتشكيل العربي.
- صف أرقام اختياري.
- حافظة محلية حتى 30 عنصرًا، لصق سريع وتثبيت العناصر المهمة ومسح السجل.
- لوحة إيموجي و3 عبارات سريعة قابلة للتعديل.
- ثيمات جاهزة وتخصيص كامل لألوان الخلفية والأزرار والأحرف والتمييز.
- صورة شخصية كخلفية أو تدرج لوني.
- التحكم باستدارة الأزرار وارتفاعها وحدودها.
- اهتزاز وصوت اختياريان.
- سحب زر المسافة لتحريك المؤشر يمينًا ويسارًا.
- حذف مستمر بالضغط المطول.
- زر سريع للتبديل إلى لوحة المفاتيح التالية.

## الخصوصية
التطبيق **لا يطلب صلاحية INTERNET**، لا توجد تحليلات أو إعلانات أو رفع للنصوص. الحافظة المحفوظة تبقى داخل SharedPreferences الخاصة بالتطبيق على الهاتف ويمكن مسحها من لوحة الحافظة.

## التفعيل
1. افتح التطبيق واضغط «تفعيل الكيبورد».
2. فعّل «مفتاح Keyboard» من إعدادات لوحات المفاتيح.
3. ارجع واضغط «اختيار مفتاح Keyboard الآن».

## البناء
```bash
gradle app:assembleDebug
```
الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
